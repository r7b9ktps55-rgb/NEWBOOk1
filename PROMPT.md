# Промт: «Домашний пульт для Android TV / Xiaomi»

Скопируй этот промт в любой AI-ассистент, чтобы воспроизвести или доработать приложение.

---

Ты — senior full-stack разработчик. Сделай **веб-приложение «пульт ДУ» для Android TV**
(Xiaomi Mi TV / Mi Box / Google TV / любой Android TV), которое разворачивается на одном
домашнем сервере и открывается со всех телефонов в доме как PWA-приложение.

## Архитектура
- **Сервер**: Node.js 20+, минимум зависимостей (`ws`, `selfsigned`, `qrcode`).
  Сервер стоит в той же Wi-Fi/LAN-сети, что и телевизор, и управляет ТВ по **ADB over network**
  (порт 5555). Команды на ТВ идут через одну постоянную `adb shell`-сессию на каждый ТВ
  (без перезапуска adb на каждое нажатие) с очередью и склейкой нажатий
  (`input keyevent A B C`), чтобы свайпы не тормозили.
- **Клиент**: чистый HTML/CSS/JS без сборки, mobile-first, тёмная тема, крупные кнопки,
  вибро-отклик. Связь с сервером — WebSocket (нажатия) + REST (настройки).
- **PWA**: manifest + service worker, «Добавить на главный экран».
- **HTTP (8080) и HTTPS (8443)** с автоматически сгенерированным самоподписанным
  сертификатом — HTTPS нужен браузеру для микрофона.
- **Docker** (`network_mode: host`) + вариант без Docker (systemd).
- Все данные (список ТВ, ADB-ключи, сертификат) — в папке `data/`.

## Функции
1. **Кнопки**: питание, вход/HDMI, без звука, громкость ±, каналы ±, домой, назад, меню,
   недавние приложения, настройки, крестовина + OK, медиа (перемотка, пред., пауза, след.),
   цифры 0–9, цветные кнопки, инфо, субтитры, поиск/ассистент.
2. **Сенсорная зона (тачпад)**: свайп → стрелки (каждые ~40 px — одно нажатие),
   удержание после свайпа → авто-повтор, тап → OK, долгий тап → долгое OK.
   Переключатель «Сенсор / Крестовина».
3. **Голосовое управление**: Web Speech API (ru-RU); если браузер не умеет —
   поле ввода, куда можно надиктовать голосом с клавиатуры телефона.
   Сервер разбирает фразы на русском:
   «громче/тише [на N]», «без звука», «пауза/играй», «домой», «назад»,
   «открой ютуб/кинопоиск/…», «найди котиков на ютубе», «найди …»,
   «канал 5», «напиши …», «выключи/включи телевизор», «вверх/вниз/влево/вправо/ок».
4. **Клавиатура**: ввод текста на ТВ (латиница через `input text`,
   кириллица через ADBKeyboard), стереть, Enter.
5. **Приложения**: список установленных на ТВ приложений (LEANBACK_LAUNCHER), запуск в 1 тап.
6. **Скриншот экрана ТВ** на телефоне.
7. **Несколько телевизоров**: добавить по IP, автопоиск в сети (сканирование порта 5555),
   сопряжение для Android 11+ (Wireless debugging, `adb pair`), Wake-on-LAN по MAC.
8. **Общий доступ**: QR-код со ссылкой для остальных телефонов в доме,
   опциональный PIN-код (`ACCESS_PIN`).
9. **Статус**: индикатор подключения, авто-переподключение раз в 10 секунд.

## Облачный режим
- Сервер можно развернуть на VPS. Облако не видит домашнюю сеть, поэтому есть два «мостика»:
  1. **Tailscale на ТВ**: облако делает `adb connect 100.x.x.x:5555` через tailnet.
  2. **Домашний агент** (`agent.js`): исходящий WebSocket в облако с токеном `AGENT_TOKEN`,
     выполняет только белый список операций (кнопки, текст, приложения, скриншот, поиск ТВ, WoL).
     Ставится одной командой: Termux на старом Android-телефоне, systemd на Raspberry Pi или Docker.
     Код агента сервер раздаёт сам (`/agent.tgz`).
- Единый интерфейс «шлюза» (`LocalGateway` / `AgentGateway`), у каждого ТВ поле `agent`.
- HTTPS через Caddy + Let's Encrypt, домен по умолчанию `<ip>.sslip.io`.
- Обязательный пароль (`ACCESS_PIN`), блокировка после 8 ошибок, cookie `HttpOnly; Secure; SameSite=Strict`,
  проверка Origin у WebSocket, сервер слушает только `127.0.0.1` за прокси.
- `deploy/cloud-setup.sh`: установка на Ubuntu/Debian одной командой (Docker, .env, Tailscale, файрвол).

## Требования к качеству
- Пользовательские строки безопасно экранируются перед отправкой в shell ТВ.
- Разрешены только известные коды клавиш (белый список).
- Мок `adb` для локальной проверки без телевизора (`ADB_PATH=./tools/fake-adb.js`).
- Пошаговая инструкция на русском: включение отладки на Xiaomi, установка сервера,
  первое подключение, установка на телефоны, решение проблем.
