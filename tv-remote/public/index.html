Добавить телевизор
Сопряжение (Android 11+ / Google TV)

На ТВ: Настройки → Для разработчиков → Отладка по Wi-Fi → «Подключить по коду». Введите сюда порт и код с экрана ТВ.

Поставить на другие телефоны

Отсканируйте QR камерой телефона и выберите «Добавить на главный экран». Ссылка с HTTPS нужна для голосового управления.
