# 📺 Домашний пульт для Android TV / Xiaomi

Веб-пульт (PWA) для любых Android TV: ставится на домашний сервер и открывается со всех
телефонов в доме. Управляет телевизором по ADB через Wi-Fi.

- **Кнопки**: питание, громкость, каналы, медиа, цифры, цветные, Домой/Назад/Меню
- **Сенсорная зона**: свайпы, тап = OK, удержание = прокрутка
- **Голос**: «открой ютуб», «громче на 5», «найди котиков на ютубе», «пауза»…
- **Текст** в поиск на ТВ, **список приложений**, **скриншот экрана ТВ**
- Несколько телевизоров, автопоиск, сопряжение Android 11+, Wake-on-LAN, PIN, QR для раздачи

📄 [PROMPT.md](PROMPT.md): промт, по которому сделано приложение
🛠 [INSTALL.md](INSTALL.md): пошаговая установка

```bash
cd tv-remote
docker compose up -d --build     # или: npm ci && npm start
# открыть http://IP-сервера:8080 на телефоне
```

Разработка без телевизора: `cd tv-remote && npm install && npm run dev` (имитация adb), тесты: `npm test`.
