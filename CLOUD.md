# ☁️ Пульт в облаке: пошаговая установка

Пульт живёт на облачном сервере (VPS) и открывается с любого телефона, даже не из дома:
`https://ваш-адрес`. Вход по паролю, настоящий HTTPS-сертификат, работают голос и установка
на главный экран.

## Главное, что нужно понять

Облачный сервер стоит в дата-центре, а телевизор у вас дома за роутером, поэтому напрямую
сервер ТВ не видит. Нужен «мостик». Есть два способа, выберите один:

| | **A. Tailscale на телевизоре** | **B. Домашний агент** |
|---|---|---|
| Что нужно дома | только телевизор | любое устройство, которое всегда включено: **старый Android-телефон**, Raspberry Pi, ПК, NAS |
| Как работает | ТВ и сервер объединяются в защищённую частную сеть Tailscale (бесплатно) | агент сам подключается к облаку по HTTPS и выполняет команды |
| Сложность | ставите приложение Tailscale на ТВ | одна команда на домашнем устройстве |
| Включение ТВ из сна (Wake-on-LAN) | ❌ | ✅ |
| Автопоиск ТВ в сети | ❌ | ✅ |
| Когда выбирать | ТВ на Android TV 9–10 (Mi Box S, Mi TV P1 и т.п.) | если Tailscale на ТВ не заводится, или ТВ несколько |

```
 A)  Телефоны ──HTTPS──▶ Облако ──Tailscale (VPN)──▶ Телевизор
 B)  Телефоны ──HTTPS──▶ Облако ◀──HTTPS── Агент дома ──ADB по Wi-Fi──▶ Телевизор
```

## Шаг 1. Арендуем сервер

Подойдёт самый дешёвый VPS у любого провайдера: 1 vCPU, 512 МБ–1 ГБ RAM, **Ubuntu 22.04/24.04**
или Debian 12. Нужен публичный IPv4.

- Свой домен **не обязателен**: скрипт сам возьмёт бесплатный адрес вида `203-0-113-10.sslip.io`.
- Если домен есть, создайте A-запись `tv.ваш-домен.ru → IP сервера`.
- В панели провайдера (Firewall / Security Group) откройте входящие **TCP 80 и 443**.

## Шаг 2. Устанавливаем пульт одной командой

Подключитесь к серверу по SSH (`ssh root@IP-сервера`) и выполните:

```bash
apt update && apt install -y git
git clone https://github.com/r7b9ktps55-rgb/NEWBOOk1.git
cd NEWBOOk1/tv-remote
sudo bash deploy/cloud-setup.sh
```

> Если репозиторий приватный, git попросит логин GitHub и токен
> (Settings → Developer settings → Personal access tokens). Или скопируйте папку `tv-remote`
> на сервер через `scp -r tv-remote root@IP:~/`.

Скрипт задаст 3 вопроса (на всё можно нажимать Enter):
1. **Домен.** По умолчанию бесплатный `…sslip.io`.
2. **Пароль для входа в пульт.** По умолчанию случайный, запишите его.
3. **Установить Tailscale?** Ответьте `y`, если выбрали способ A.

Затем он сам поставит Docker, получит HTTPS-сертификат и запустит пульт. В конце покажет:

```
 ✅ Пульт развёрнут
 Адрес:   https://203-0-113-10.sslip.io
 Пароль:  4f9a1c02be
```

## Шаг 3. Подключаем телевизор

Сначала включите на ТВ отладку (подробно в [INSTALL.md, шаг 1](INSTALL.md#шаг-1-включаем-отладку-на-телевизоре-3-минуты)):
**Настройки → Об устройстве → «Сборка» 7 раз → Для разработчиков → «Отладка по USB» (и «Отладка по сети», если есть)**.

### Способ A: Tailscale на телевизоре
1. На ТВ откройте **Google Play** → найдите **Tailscale** → установите.
2. Войдите в **тот же аккаунт**, под которым на шаге 2 авторизовали сервер.
3. В приложении Tailscale на ТВ появится адрес вида **`100.101.102.103`**. Запомните его.
4. Если в приложении есть автозапуск, включите его, чтобы Tailscale работал после перезагрузки ТВ.
5. Откройте пульт на телефоне → **Настройки → Добавить телевизор**:
   - «Как сервер достаёт до ТВ»: **Напрямую с сервера (Tailscale / VPN)**
   - IP: **`100.101.102.103`**
6. На экране ТВ нажмите **«Разрешить»** в окне отладки (галочка «Всегда разрешать»).

Если сервер уже работал, а Tailscale вы поставили позже:
`curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up`, затем
`docker compose -f docker-compose.cloud.yml restart tv-remote`.

> На Android TV 11+ / Google TV порт отладки может быть не 5555. Тогда используйте
> **Настройки → Сопряжение** в пульте с Tailscale-адресом ТВ. Если не получается, выберите способ B.

### Способ B: домашний агент
1. Откройте пульт → **Настройки → «Домашний агент» → «Показать команды установки»**.
   Там готовые команды с вашим адресом и секретным токеном.
2. Выполните одну из них **дома**:

**Старый Android-телефон** (самый простой вариант: подойдёт любой телефон на Android 7+):
1. Установите **Termux** из F-Droid (https://f-droid.org/packages/com.termux/). Версия из Google Play устарела.
2. Для автозапуска также установите **Termux:Boot** из F-Droid и один раз откройте его.
3. В Termux вставьте команду из пульта:
   ```bash
   curl -fsSL https://ВАШ-АДРЕС/agent-termux.sh | SERVER_URL=https://ВАШ-АДРЕС AGENT_TOKEN=… AGENT_NAME=Дом bash
   ```
4. В настройках Android отключите для Termux **оптимизацию батареи** и оставьте телефон на зарядке.

**Raspberry Pi / Linux-компьютер:**
```bash
curl -fsSL https://ВАШ-АДРЕС/agent-linux.sh | sudo SERVER_URL=https://ВАШ-АДРЕС AGENT_TOKEN=… AGENT_NAME=Дом bash
```
Агент установится как служба и будет стартовать сам.

**Docker** (NAS, домашний сервер): в папке `tv-remote` создайте файл `agent.env`
с переменными `SERVER_URL`, `AGENT_TOKEN`, `AGENT_NAME` и выполните
`docker compose -f docker-compose.agent.yml up -d --build`.

**Windows / macOS:** установите Node.js и adb (Platform Tools), затем
`npm ci --omit=dev` и `node agent.js` с теми же переменными.

3. В пульте агент появится со статусом **«в сети»** (зелёная точка).
4. **Добавить телевизор** → «Через домашний агент «Дом»» → домашний IP ТВ (`192.168.1.50`).
   Можно нажать **«Найти телевизоры в сети»**: агент просканирует домашнюю сеть.
5. На ТВ нажмите **«Разрешить»** в окне отладки.

## Шаг 4. Ставим на телефоны всей семьи

1. Откройте `https://ваш-адрес` на телефоне и введите пароль.
2. **Android/Chrome:** меню ⋮ → **«Установить приложение»**. **iPhone/Safari:** «Поделиться» → **«На экран Домой»**.
3. Остальным: **Настройки → «Поставить на другие телефоны»**, там QR-код.
   Каждый вводит пароль один раз, дальше пульт его помнит.

Голос работает сразу: адрес с настоящим HTTPS, без предупреждений.

## Обслуживание

```bash
cd ~/NEWBOOk1/tv-remote
docker compose -f docker-compose.cloud.yml logs -f              # логи
docker compose -f docker-compose.cloud.yml restart              # перезапуск
git pull && docker compose -f docker-compose.cloud.yml up -d --build   # обновление
nano .env && docker compose -f docker-compose.cloud.yml up -d   # сменить пароль/домен
```

Сменили пароль? Все телефоны попросят ввести новый. Сменили `AGENT_TOKEN`? Переустановите агента.

Бэкап: папка `data/` (список ТВ и ADB-ключ сервера) и файл `.env`.

## Безопасность

- Пароль обязателен. Без `ACCESS_PIN` сервер в облаке не запустится.
- 8 неверных попыток входа блокируют IP на 15 минут.
- Наружу открыты только 80/443 (Caddy). Сам пульт слушает `127.0.0.1:8080`.
- Агент может выполнять на ТВ **только** команды пульта (кнопки, текст, запуск приложений,
  скриншот), но не произвольный shell.
- Порт ADB (5555) **никогда** не пробрасывайте на роутере в интернет.

## Проблемы

| Симптом | Что делать |
|---|---|
| HTTPS не открывается | Домен смотрит на IP сервера? Открыты 80/443 у провайдера? `docker compose -f docker-compose.cloud.yml logs caddy` |
| «Домашний агент не в сети» | Устройство дома включено? Termux не убит экономией батареи? Лог агента: `tail -f ~/tv-agent/agent.log` или `journalctl -u tv-agent -f` |
| Агент пишет «Сервер отклонил токен» | Скопируйте команду заново из пульта (Настройки → Домашний агент) |
| Через Tailscale ТВ «не в сети» | На сервере выполните `tailscale ping 100.x.x.x`. Tailscale на ТВ запущен? Отладка на ТВ включена? |
| Жёлтая точка | Подтвердите отладку на экране ТВ |
| Задержка нажатий | Облако добавляет 50–150 мс. Выбирайте VPS поближе к дому |
