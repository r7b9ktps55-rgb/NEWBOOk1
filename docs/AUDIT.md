## Что остаётся за вами

1. **Где запускать.** Gemini API не принимает запросы с российских IP — нужен сервер в поддерживаемой стране.
2. **HTTPS**, если сайт доступен из интернета: `docker compose --profile https up -d` (README, «Доступ из интернета по HTTPS»).
3. **Лимиты в Google**: месячный лимит расходов и бюджет с письмами (README, «Расходы на Gemini»).
4. **Права ключей и файлов**: fine-grained токен GitHub только на репозиторий хранилища и со сроком, ключ Gemini ограничен Generative Language API, `chmod 600 .env`.
5. **Копии вне сервера**: `BACKUP_DIR` на другом диске или регулярное копирование `data/backups`.
6. **Уведомления**: задать `NOTIFY_URL`.
7. Раз в месяц пересобирать образ (`docker compose build --pull`) и, по желанию, сканировать его (`docker scout cves` или `trivy`).

## Не исправлено (низкий риск)

- Если остановить контейнер посреди длинного запроса, текущая часть формата после перезапуска делается заново (оплачивается повторно).
- Загрузка без `Content-Length` (только авторизованным клиентом, не браузером) не ограничена на уровне всего запроса; лимит на каждый файл действует.
- Не заданы `max_output_tokens` и бюджет «размышлений» модели — расход ограничен числом запросов, а не токенов.
