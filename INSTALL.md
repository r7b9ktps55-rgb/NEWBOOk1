# Пошаговая установка пульта для Android TV / Xiaomi

Как это устроено:

```
 Телефоны в доме ──Wi-Fi──▶  Домашний сервер (пульт)  ──ADB по сети──▶  Телевизор
 (браузер / PWA)             Raspberry Pi / ПК / NAS                    Xiaomi / Android TV
```

> ⚠️ Это инструкция для **домашнего** сервера (в той же сети, что и ТВ): Raspberry Pi, ноутбук, NAS.
> Хотите развернуть на **облачном сервере** с доступом отовсюду? Смотрите **[CLOUD.md](CLOUD.md)**.
> Шаг 1 (отладка на ТВ) нужен в обоих случаях.

---

## Шаг 1. Включаем отладку на телевизоре (≈3 минуты)

### Xiaomi Mi Box / Mi TV Stick / Mi TV на Android TV 9–10 (PatchWall тоже)
1. **Настройки** → **Настройки устройства** → **Об устройстве**.
2. Нажмите на **«Сборка»** 7 раз подряд, пока не появится «Вы стали разработчиком».
3. Назад → **Настройки устройства** → **Для разработчиков**.
4. Включите **«Отладка по USB»**. На многих моделях тут же есть пункт
   **«Отладка по сети» / «ADB по сети»**: включите и его.
5. Узнайте IP телевизора: **Настройки** → **Сеть и Интернет** → ваша Wi-Fi-сеть → **IP-адрес**
   (например `192.168.1.50`).

### Google TV / Android TV 11 и новее (Xiaomi TV A/A Pro, Mi Box S 2-го поколения, Chromecast и др.)
1. Шаги 1–3 те же (на Google TV: **Настройки → Система → О системе → Сборка ОС**, 7 раз).
2. В **«Для разработчиков»** включите **«Отладка по USB»** и **«Отладка по Wi-Fi»**.
3. Если подключение по порту 5555 не заработает, используйте сопряжение по коду (шаг 4Б).

> 💡 Закрепите за телевизором постоянный IP в настройках роутера (раздел DHCP, «Резервирование адресов»),
> иначе после перезагрузки роутера адрес может смениться.

## Шаг 2. Устанавливаем сервер

### Вариант А: Docker (рекомендую)

На сервере (Linux / Raspberry Pi OS / Ubuntu / Synology / Unraid) должны стоять `git` и Docker:

```bash
# 1. Docker, если ещё не установлен
curl -fsSL https://get.docker.com | sh

# 2. Скачать проект
git clone https://github.com/r7b9ktps55-rgb/NEWBOOk1.git
cd NEWBOOk1/tv-remote

# 3. (необязательно) включить PIN и сразу прописать телевизор:
#    откройте docker-compose.yml и раскомментируйте ACCESS_PIN / TV_HOSTS
nano docker-compose.yml

# 4. Запустить
docker compose up -d --build

# 5. Посмотреть адреса пульта
docker compose logs -f
```

В логах появится:
```
Пульт запущен:
   http://192.168.1.10:8080
   https://192.168.1.10:8443
```

Обновление на новую версию: `git pull && docker compose up -d --build`.

### Вариант Б: без Docker (Node.js + adb)

```bash
# Debian / Ubuntu / Raspberry Pi OS
sudo apt update
sudo apt install -y adb git curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

git clone https://github.com/r7b9ktps55-rgb/NEWBOOk1.git
cd NEWBOOk1/tv-remote
npm ci --omit=dev
npm start
```

Автозапуск при включении сервера:
```bash
# поправьте User и WorkingDirectory под себя
nano tv-remote.service
sudo cp tv-remote.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tv-remote
journalctl -u tv-remote -f        # логи
```

**Windows**: поставьте [Node.js LTS](https://nodejs.org) и
[Platform Tools](https://developer.android.com/tools/releases/platform-tools) (в них есть `adb.exe`),
добавьте папку с `adb.exe` в PATH, затем в папке `tv-remote` выполните `npm ci` и `npm start`.

### Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8080` | HTTP-порт |
| `HTTPS_PORT` | `8443` | HTTPS-порт (нужен для голоса) |
| `HTTPS` | `1` | `0` отключает HTTPS |
| `ACCESS_PIN` | пусто | PIN-код для входа в пульт |
| `TV_HOSTS` | пусто | ТВ при первом запуске: `Зал=192.168.1.50,Кухня=192.168.1.51` |
| `ADB_PATH` | `adb` | путь к adb |
| `DATA_DIR` | `./data` | где хранить ТВ, ключи и сертификат |

## Шаг 3. Первое подключение к телевизору

1. На телефоне (в той же Wi-Fi-сети) откройте `http://IP-СЕРВЕРА:8080`.
2. Откроется окно **«Телевизоры»**. Нажмите **«Добавить телевизор»**, введите название
   (например «Зал») и IP телевизора. Можно нажать **«Найти телевизоры в сети»**, и пульт
   сам найдёт устройства с включённой отладкой.
3. **На экране телевизора** появится вопрос **«Разрешить отладку по USB?»**.
   Отметьте **«Всегда разрешать с этого компьютера»** и нажмите **OK**.
   Это нужно сделать один раз: ключ сохранится в папке `data/`.
4. Точка рядом с названием ТВ станет зелёной. Готово, можно управлять!

### 4Б. Если ТВ на Android 11+ и не подключается
1. На ТВ: **Для разработчиков → Отладка по Wi-Fi → Подключить устройство с помощью кода**.
2. На экране будут **код из 6 цифр**, **IP:порт сопряжения** и выше, на экране «Отладка по Wi-Fi»,
   **IP:порт подключения**.
3. В пульте: **Настройки → Сопряжение**, выберите ТВ и введите порт сопряжения, код и порт подключения.

## Шаг 4. Ставим пульт на все телефоны в доме

1. В пульте откройте **Настройки (⚙ справа вверху) → «Поставить на другие телефоны»**:
   там QR-коды со ссылками.
2. Отсканируйте QR камерой другого телефона.
3. **Android (Chrome)**: меню **⋮** → **«Добавить на главный экран»** (или «Установить приложение»).
   **iPhone (Safari)**: кнопка **«Поделиться»** → **«На экран Домой»**.
4. На главном экране появится иконка **«Пульт»**, и он откроется как обычное приложение.

### Какую ссылку выбрать: HTTP или HTTPS?
- **`http://…:8080`** открывается без предупреждений. Голос работает через **микрофон клавиатуры**:
  нажмите оранжевую кнопку 🎤 в пульте, потом микрофон на клавиатуре телефона и скажите команду.
- **`https://…:8443`** даёт полноценное распознавание речи прямо в пульте. Сертификат самоподписанный,
  поэтому при первом входе браузер предупредит: нажмите **«Дополнительно» → «Перейти на сайт»**.
  Один раз на каждом телефоне.

## Что умеет пульт

| Раздел | Возможности |
|---|---|
| **Пульт** | Питание, источник/HDMI, без звука, настройки ТВ, **сенсорная зона** или крестовина, Назад/Домой/Недавние, громкость, каналы, медиа-кнопки, **голос** |
| **Сенсор** | свайп = стрелка (длинный свайп = несколько шагов), **тап = OK**, **долгий тап = долгое OK**, задержите палец после свайпа, чтобы прокручивать дальше |
| **Приложения** | все приложения с ТВ, запуск в один тап |
| **Текст** | ввод текста в поиск на ТВ, режим «печатать сразу», стереть, Enter, поиск |
| **Ещё** | цифры, цветные кнопки, меню, субтитры, ассистент, **скриншот экрана ТВ** |
| **Несколько ТВ** | короткое нажатие на название ТВ вверху переключает между ними |

### Голосовые команды (примеры)
- «громче», «тише на 5», «без звука»
- «пауза», «продолжи», «перемотай вперёд», «следующее»
- «открой ютуб», «запусти кинопоиск», «включи нетфликс», «ютуб»
- «найди котиков на ютубе», «включи на ютубе лофи», «найди фильм интерстеллар»
- «канал 5», «следующий канал»
- «домой», «назад», «вниз 3 раза», «ок», «источник»
- «напиши Привет», «выключи телевизор», «включи телевизор»

## Дополнительно

### Русские буквы в поле ввода
Стандартный `adb input` умеет только латиницу. Для кириллицы установите на ТВ бесплатную
клавиатуру **ADBKeyboard** (https://github.com/senzhk/ADBKeyBoard, файл `ADBKeyboard.apk`):
```bash
adb connect 192.168.1.50:5555
adb install ADBKeyboard.apk
```
С Docker: `docker exec -it tv-remote adb install /app/data/ADBKeyboard.apk`
(предварительно положите apk в папку `data/`). Пульт сам переключится на неё для ввода
кириллицы и вернёт вашу обычную клавиатуру.

### Включение ТВ кнопкой питания
Когда ТВ в глубоком сне, ADB отключается. Укажите **MAC-адрес** телевизора в настройках
(✎ у телевизора) — пульт пошлёт Wake-on-LAN-пакет. MAC: **Настройки → Об устройстве → Статус**.
На Xiaomi также помогает **Настройки → Питание → «Быстрое включение»**.

### Доступ не из дома
Разверните пульт в облаке, см. [CLOUD.md](CLOUD.md). Не пробрасывайте порты пульта и ADB (5555) в интернет!

## Решение проблем

| Проблема | Решение |
|---|---|
| Красная точка, «не в сети» | ТВ включён? IP правильный? Отладка включена? Сервер в той же сети? Проверьте с сервера: `adb connect IP:5555` |
| Жёлтая точка, «ждёт подтверждения» | Подойдите к ТВ и нажмите «Разрешить» в окне отладки (галочка «Всегда разрешать») |
| После перезагрузки ТВ снова спрашивает разрешение | Не потеряна ли папка `data/`? Docker: проверьте, что volume `./data` подключён |
| Подключение отклоняется (connection refused) | ТВ на Android 11+: используйте «Сопряжение» (шаг 4Б) |
| Свайпы слегка запаздывают | Это нормально для ADB (≈0,1–0,3 с); нажатия склеиваются, ничего не теряется. Включите «Чувствительный сенсор» в настройках |
| Не работает распознавание речи | Откройте HTTPS-ссылку или диктуйте через микрофон клавиатуры |
| Скриншот чёрный | Защищённое видео (Netflix, Кинопоиск и т.п.) нельзя заскриншотить, это DRM |
| Не находит ТВ автопоиском | Автопоиск сканирует только /24-подсеть сервера и только порт 5555. Добавьте IP вручную |
| Проверить без телевизора | `npm run dev`: запускает пульт с имитацией adb, команды видны в логе |
